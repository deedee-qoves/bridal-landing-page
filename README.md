# QOVES Wedding Day Protocol landing page

Static site, no build step. Open `index.html` in a browser to preview.

## Publish on GitHub Pages

1. On github.com, create a new repository (e.g. `qoves-wedding`).
2. Click "uploading an existing file", drag in everything inside this folder (`index.html`, `README.md` and the `assets` folder), then commit.
3. Go to Settings › Pages, set Source to "Deploy from a branch", pick `main` and `/ (root)`, and save.

The site goes live at `https://<your-username>.github.io/qoves-wedding/` within a minute or two.

## Files

- `index.html`: the whole page, styles and the small script for the slider and advisor carousel
- `assets/fonts`: PP Neue Montreal and Zagma (use the licensed web files)
- `assets/img`: hero gradient, before/projection photos, makeup trial photo, advisor headshots
